FARMPro Survey v0.6 PWA
1. Create a GitHub repository (example: farmpro-survey).
2. Upload ALL files from this package to the repository root.
3. GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Wait for the HTTPS GitHub Pages link.
5. On iPhone open that link in Safari > Share > Add to Home Screen > Add.
6. Open FARMPro once while online; afterward the app shell can load offline.

The existing FARMPro IndexedDB draft/submission storage is retained.
Do not clear Safari website data before pending records are synced/exported.
Automatic server sync still needs a Central Server API Endpoint in Sync Settings.
